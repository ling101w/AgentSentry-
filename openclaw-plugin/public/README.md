# openclaw-plugin/public

8765 OpenClaw 插件前端资源目录。

页面入口：

- `index.html`：实时语义动作图、会话故事、裁决 Inspector 与执行回放。
- `command-lab.html`：演示实验页。交互复现攻击链，并对公开 benchmark 做单条复测。
- `demo/selected-cases/`：真实治理过程演示，回放注入 / 工具劫持 / 记忆投毒三条 benchmark 轨迹。入口：`/demo`。
- `security-screen.html`：全局安全态势与 3D 拓扑补充视图。

所有样式和脚本都本地加载，不依赖外部 CDN。
